# Texas Instruments TLV320DAC3100 low-power stereo audio DAC with audio processing and mono Class-D speaker amplifier driver library release notes   

This driver library provides functions for supporting a [Texas Instruments TLV320DAC3100 low-power stereo audio DAC with audio processing](https://www.ti.com/product/TLV320DAC3100?utm_source=google&utm_medium=cpc&utm_campaign=asc-null-null-GPN_EN-cpc-pf-google-ww_en_cons&utm_content=TLV320DAC3100&ds_k=TLV320DAC3100&DCM=yes&gad_source=1&gad_campaignid=14388345080&gbraid=0AAAAAC068F2_uiPre6qxMuUbQf1WNXJ9Y&gclid=EAIaIQobChMIjs-c0I7DjgMVs8c8Ah3nsRcwEAAYASAAEgLDcPD_BwE&gclsrc=aw.ds) on PSOC&trade; Edge E84 Evaluation Kit (`KIT_PSE84_EVAL_EPC2`).


## What's included?

- APIs for the TLV320DAC3100 codec control

See the [README.md](./README.md) and the [API Reference Guide](./API_reference.md) for a complete description of the TLV320DAC3100.
